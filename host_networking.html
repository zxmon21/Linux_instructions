Network Watchdog: Auto-Restart eno1 on Connectivity Loss

  1. Create the watchdog script 
    sudo tee /usr/local/bin/netwatch-eno1.sh > /dev/null << 'EOF'
#!/bin/bash
TARGET="192.168.50.1"
IFACE="eno1"
FAIL_THRESHOLD=60   # seconds
CHECK_INTERVAL=5    # seconds between pings
LOGFILE="/var/log/netwatch-eno1.log"

fail_start=0

log() {
    echo "$(date '+%Y-%m-%d %H:%M:%S') $1" >> "$LOGFILE"
}

while true; do
    if ping -c 1 -W 2 "$TARGET" > /dev/null 2>&1; then
        fail_start=0
    else
        now=$(date +%s)
        if [ "$fail_start" -eq 0 ]; then
            fail_start=$now
            log "Lost connectivity to $TARGET, starting timer"
        else
            elapsed=$((now - fail_start))
            if [ "$elapsed" -ge "$FAIL_THRESHOLD" ]; then
                log "No connectivity to $TARGET for ${elapsed}s, restarting $IFACE"
                ip link set "$IFACE" down
                sleep 2
                ip link set "$IFACE" up
                log "$IFACE restarted"
                fail_start=0
                sleep 15
            fi
        fi
    fi
    sleep "$CHECK_INTERVAL"
done
EOF
  2. Make the script executable 
    sudo chmod +x /usr/local/bin/netwatch-eno1.sh
  3. Create the systemd service unit 
    sudo tee /etc/systemd/system/netwatch-eno1.service > /dev/null << 'EOF'
[Unit]
Description=Monitor eno1 connectivity to 192.168.50.1 and restart interface on prolonged failure
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/netwatch-eno1.sh
Restart=always
RestartSec=5
User=root

[Install]
WantedBy=multi-user.target
EOF
  4. Reload systemd and enable the service 
    sudo systemctl daemon-reload
sudo systemctl enable --now netwatch-eno1.service
  5. Check service status 
    sudo systemctl status netwatch-eno1.service
  6. Tail the watchdog log 
    tail -f /var/log/netwatch-eno1.log
  7. Restart the service after editing the script 
    sudo systemctl restart netwatch-eno1.service
  8. Disable the watchdog (if needed) 
    sudo systemctl disable --now netwatch-eno1.service
  9. Notes

    - Pings 192.168.50.1 via eno1 every 5 seconds
    - Restart only triggers after 60 continuous seconds of failed connectivity, not after 60 failed pings
    - After a restart, the watchdog waits 15s before resuming checks to allow DHCP/link renegotiation
    - Restarting eno1 will briefly interrupt the Home Assistant VM's bridged networking and the Huawei inverter DNAT path
    - Service auto-starts on boot via enable and auto-restarts itself if it crashes via Restart=always
    - Log file location: /var/log/netwatch-eno1.log
